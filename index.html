Projects

A few experiments I wanted to see work.

Rust, Metal, CUDA, a bit of NumPy. Inference compilers, a coding agent, some RL without the usual frameworks. Coding agents did a lot of the typing. I pointed them, I tested, I threw things away when they were wrong.

  1. 01 Rust · Metal 1★

    ksearch

    A Metal inference compiler for Gemma 4 — lowers GGUF to IR, emits MSL, and uses BEAM search to pick tilings instead of a pile of named kernels.

    View repository
  2. 02 Rust · Metal 4★

    metal-llm-server

    Local Gemma4 inference on Apple Silicon — Metal kernels, OpenAI-compatible API, continuous batching, and zero-copy GGUF loads.

    View repository
  3. 03 Rust

    rs-agent

    A local overnight coding factory — wish a backlog, fleet workers implement on isolated worktrees, and Deep Context keeps huge repos out of the model window.

    View repository
  4. 04 Python · NumPy 1★

    2048-rl

    A from-scratch RL arcade — custom DQN, Adam, and replay — across 2048, Tetris, Breakout, Pong, and more. No Gymnasium. No SB3.

    View repository
  5. 05 Rust · Metal 1★

    metal-operators

    GPU KMeans, KNN, and PCA on Apple Metal — Lloyd’s algorithm entirely on-device, with multiple kernel variants for speed.

    View repository
  6. 06 Jupyter 52★

    notebooks

    A living lab of LLM compression, RAG, fine-tuning, and vision experiments — the most-starred collection on my GitHub.

    View repository
  7. 07 JS · Rust 1★

    openchessengine

    Dependency-free chess UI plus a native Rust engine with alpha-beta search, transposition tables, and Stockfish match harnesses.

    View repository
